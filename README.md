# Learn Together

Application Android développée avec Jetpack Compose .

## Description

Learn Together affiche une liste d'articles à propos de plusieurs bibliothèques Jetpack. Cet exercice implémente l'écran de tutoriel Jetpack Compose.

## Fonctionnalités de l'écran

- Image en pleine largeur
- Titre avec taille de police personnalisée
- Paragraphes de description avec alignement justifié

## Technologies utilisées

- Kotlin
- Jetpack Compose
- Material 3
